# E-Learning Platform UI

A modern and responsive E-Learning Platform User Interface built using HTML, CSS, and JavaScript. This project includes course listings, progress tracking, and video embedding features with an attractive multi-page design.

---

## 🚀 Features

- Responsive Multi-Page Interface
- Modern UI Design
- Interactive Navigation Bar
- Course Listing Cards
- Progress Tracking Dashboard
- Embedded Video Learning Section
- Mobile-Friendly Layout
- Smooth Hover Effects and Animations

---

## 📂 Pages

### 1. Home Page
- Hero Section
- Features Section
- Navigation Menu

### 2. Courses Page
- Popular Courses
- Course Cards
- Enroll Button

### 3. Dashboard Page
- Learning Progress Bar
- Video Embedding
- Student Dashboard

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
